# 歼-8B 战斗机 · 三维结构 / 气动仿真平台

> J-8B "Finback-B" · 双发高空高速截击机 · 交互式机构 / 气动模型

基于 **Three.js** 的纯前端交互式三维模型。完整机体结构、可动机构、武器挂载与纵向气动仿真，**无后端、无构建步骤**，打开网页即可运行。

## ✨ 功能特性

### 机体结构
- 按公开资料尺寸放样建模：机长 21.59 m、翼展 9.34 m、双发涡喷-13A
- 座舱盖、背脊、两侧进气道、三角翼、全动平尾、垂尾、腹鳍等完整外形
- 程序化 PBR 贴图：铆钉、掉漆、油污、蒙皮接缝（基于高度图 + Sobel 算子生成法线/凹凸）
- PMREM 环境反射 + ACES Filmic 色调映射

### 可动机构
| 机构 | 行程 / 说明 |
| --- | --- |
| 襟翼 FLAPS | 后缘下偏，增升同时显著增大配平阻力 |
| 减速板 SPEEDBRAKE | 后机身两侧液压板，向外张开 60° |
| 起落架 GEAR | 前起落架前收 + 主起落架内收，收上时舱门关闭 |
| 座舱盖 CANOPY | 开启 / 关闭 |
| 全动平尾 STAB | −25° ~ +25°，直接决定俯仰力矩与迎角 |

所有机构均以真实铰链位置为轴做连续性动画。

### 武器挂载
5 个外挂点（左右内翼 / 左右外翼 / 机腹中线），可选 **PL-2 / PL-5 / PL-8** 空空导弹、火箭巢、航弹或副油箱，模型上实时可见；挂载变化同步作用于气动模型（阻力 / 重量 / 惯量）。内置全空载、截击、对地、转场四种预设构型。

### 气动仿真
- ISA 标准大气模型、跨音速波阻
- 含涡升力与失速衰减的 C<sub>L</sub>-α 曲线（迎角约 16° 失速，放襟翼后约 18°）
- 2-DOF 纵向动力学（速度 + 航迹），电传目标迎角配平
- 实时遥测：Ma、空速、高度、迎角、俯仰角、爬升率、过载、C<sub>L</sub> / C<sub>D</sub> / 升阻比、速度包线
- C<sub>L</sub>-α 与 C<sub>D</sub>-α 特性曲线实时绘制

## 📁 文件结构

```
.
├── index.html            # 页面骨架、UI 面板、脚本引入
├── css/style.css         # 仪表与面板样式
├── js/
│   ├── aero.js           # 气动核心：大气、气动系数、动力学积分、外挂点定义
│   ├── weapons.js        # 武器工厂：导弹 / 火箭巢 / 航弹 / 副油箱与挂架
│   ├── airframe.js       # 机体几何：机身放样、机翼、尾翼、进气道、座舱
│   ├── details.js        # 细节件：空速管、机炮、天线、座舱内部
│   ├── mechanisms.js     # 可动机构：襟翼、减速板、起落架、座舱盖、全动平尾
│   ├── textures.js       # 程序化 PBR 贴图工厂
│   └── main.js           # 渲染主循环、交互绑定、镜头控制、遥测刷新
├── libs/                 # Three.js r137 + OrbitControls（本地内置，离线可用）
├── tools/
│   ├── test-aero.js      # 气动模型离线校验
│   └── push-to-github.js # 通过 GitHub API 一键发布 + 开启 Pages
└── .nojekyll             # 跳过 GitHub Pages 的 Jekyll 处理
```

## 🚀 本地运行

无需安装任何依赖，三种方式任选：

```bash
# 1. 任意静态服务器
python -m http.server 8000

# 2. Node
npx serve .

# 3. 直接双击 index.html 也可以用
```

浏览器访问 <http://localhost:8000>。
